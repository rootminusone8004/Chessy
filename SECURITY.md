# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Chessy, please do not open a public issue. Instead, report it responsibly by contacting the maintainer or opening a private security advisory on GitHub.

All security reports will be acknowledged promptly and investigated.
